# BKCC Activos IN-OUT

App de tracking de activos retornables (pallets CHEP, chapadur, vacíos, barriles) entre Beccacece Hnos SA y planta CMQ/ABInBev, más módulo de Deuda de Clientes.

Single-file HTML — abrir `BKCC_Activos_IN-OUT_v8.html` directamente en el navegador, o publicarlo con GitHub Pages.

## Módulos
- Salidas/Entradas con Planta (CMQ)
- NAC
- CHEP Paletas
- Parque de Envases (DPO 2.1 · R3.3)
- Deuda de Clientes (activos retornables en poder de clientes)
